# Heritage Tours

A Node.js and Express app for searching heritage tours and booking places.

## Requirements

- Node.js and npm

## Run locally

1. In a terminal, go to the project folder.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the server:

   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

The app uses the SQLite database in `database.db`.
